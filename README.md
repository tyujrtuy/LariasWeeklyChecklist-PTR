# LariasWeeklyChecklist

Larias' Weekly Checklist 主插件 + 简体中文配套插件。

目录结构：

- `LariasWeeklyChecklist`：主插件
- `LariasWeeklyChecklist_Localization`：简体中文本地化配套插件

安装时把两个文件夹放入 `World of Warcraft\_retail_\Interface\AddOns\`。

## 官方原版 + Localization 的说明

这个 release 的主插件不是官方原版，而是额外加入了简体中文语言选项、小号汇总左侧锚定，
以及更不透明的弹出背景。中文文字主要来自 `LariasWeeklyChecklist_Localization`；只装
localization 时，中文客户端通常也能显示中文，但不会包含上述主插件调整。

要获得与当前 release 完全一致的体验，请直接安装完整 zip，不要用官方原版主插件替换其中
的 `LariasWeeklyChecklist`。
